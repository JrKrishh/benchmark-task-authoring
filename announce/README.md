# announce/

Ready-to-paste copy for sharing this skill with other task authors. Templates, not
announcements — adapt the voice, keep the specifics.

| file | use it for |
|---|---|
| [`intro-message.md`](intro-message.md) | First contact — someone who has never seen the skill. Chat and email versions |
| [`update-message.md`](update-message.md) | Telling existing users what changed. Chat, one-liner and email versions |

Both are written in the first person, from the perspective of someone who has authored tasks
and is passing on what it cost them. That framing is doing real work — it is why the copy leads
with a concrete failure (three CI runs, none of them about difficulty) rather than a feature
list. If you rewrite it, keep a specific number you actually measured; the generic version of
this pitch reads as noise.

Two things to change before sending:

- **the signature** — `<your name>` in the email version
- **any numbers you are quoting as your own** — the intro says "~30 slots"; say what is true
  for you, or cut the clause

Nothing here contains task content, repo identifiers, or program names. If you adapt these,
keep it that way: whatever you paste into a shared channel is as public as this repo.
